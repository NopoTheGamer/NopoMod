Using [this repo](https://github.com/NopoTheGamer/rare-crop-graph) you can create graphs of your farming rare crops using the mods config

### Tutorial
1. Install python, matplotlib, pandas (ask google)
2. Download main.py
3. In the same folder put your config file (.minecraft/nopo/config.json) Make sure to replace the example config !
4. Run the script
5. You can edit the script to tweak the information shown
